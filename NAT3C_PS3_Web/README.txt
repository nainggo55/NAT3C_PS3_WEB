# NAT3C PS3 — Página web en Python

## 1. Instalar Python
Instalá Python 3.10 o superior.

## 2. Abrir la carpeta en Visual Studio Code

## 3. Instalar Flask
En la terminal de VS Code:

```bash
pip install flask
```

## 4. Ejecutar
```bash
python app.py
```

Después abrí en el navegador:

http://127.0.0.1:5000

## Cambiar WhatsApp
Abrí `templates/index.html` y buscá:

https://wa.me/

Reemplazalo por tu enlace de WhatsApp.

Las dos imágenes que enviaste ya están incluidas en `static/img/`.
